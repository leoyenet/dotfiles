# Dotfiles

My personal CachyOS desktop configuration, built around Hyprland and Noctalia with Catppuccin themes.

- **Desktop:** Hyprland, Noctalia, GTK, and Qt themes
- **Terminal and shell:** Kitty, Alacritty, Foot, Fish, and Starship
- **Tools:** Neovim, Micro, Zed, Yazi, btop, and lazygit
- **Apps:** Zen Browser customizations and Spicetify themes

## Usage

Back up your existing configs, then copy the folders you want into `~/.config/`. Install the matching applications separately and review paths, keybindings, and monitor settings for your machine.

These configs are tailored to my setup; some depend on CachyOS defaults.
